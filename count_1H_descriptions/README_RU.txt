README - count_1H_descriptions.py (русская версия)
=================================================

Исследование опубликованных описаний спектров ¹H ЯМР (Organic Letters, первое полугодие 2026 г.)
Версия: 17 октября 2026 г.

Автор: Артур В. Ештуков-Щеглов (Artur V. Eshtukov-Shcheglov)
Код написан с помощью Claude Opus 5.5 (Anthropic), проверен и протестирован автором.

Основной является английская версия (README.txt); это перевод для удобства.


1. Назначение
-------------
Скрипт читает PDF-файлы Supporting Information (SI) и находит в них все текстовые
описания спектров ¹H ЯМР, например

    1H NMR (400 MHz, CDCl3) δ 7.41 (d, J = 6.9 Hz, 2H), ...
    1H NMR (300 MHz, CDCl3): 7.35-7.28 (m, 2H), ...        (без δ)

Распознаётся и δ, набранный шрифтом Symbol (при извлечении текста из PDF он
превращается в служебный символ).

Для каждого описания он записывает метку соединения перед ним (например, 3a)
и помечает описания, которые, вероятно, не относятся к новым соединениям:

    KNOWN?     рядом с описанием написано «known compound», «in agreement with
               the literature», «matched the reported data» и т. п.
    CITATION   сразу после метки или названия соединения стоит ссылка на
               литературу (надстрочная цифра или [n])
    REPEAT     для той же метки уже есть описание (несколько растворителей,
               ротамеры, повторный опыт); соединение считается один раз

Для перекрёстной проверки скрипт также считает описания спектров ¹³C ЯМР и
значения HRMS «found». Данные HRMS обычно приводят только для новых соединений,
поэтому сильное расхождение между числом описаний ¹H без пометок и числом
значений HRMS указывает на SI, которое стоит проверить вручную.


2. ВАЖНО - результат нужно проверять вручную
---------------------------------------------
Скрипт - вспомогательный инструмент, а не правило подсчёта. В исследовании
число соединений (n) определялось чтением каждого SI по правилам первого прохода
(соединения, отмеченные авторами как известные, не учитываются; ссылка,
относящаяся только к методике синтеза, не делает соединение известным; пептиды,
полученные твердофазным синтезом (SPPS), не учитываются; несколько описаний
одного соединения считаются один раз).

Проверка по числам, определённым вручную для 13 статей:
    точно или в пределах ±2 соединений ..... 9 статей из 13
    большее расхождение .................... 4 статьи из 13 (−4, +3, −11, +8)
Большие расхождения связаны в основном с тем, что известные соединения были
пропущены или ошибочно помечены. Рассматривайте результат как список
кандидатов, а не как окончательное число.


3. Что нужно
------------
Python 3.9 или новее и два пакета:
    pymupdf   (чтение PDF-файлов)
    openpyxl  (запись таблицы Excel)
Установить один раз:  python -m pip install -r requirements.txt  (из главной
папки; проверенные версии)  или  python -m pip install pymupdf openpyxl
Если пакета нет, скрипт останавливается и пишет, какого именно.


4. Как запустить
----------------
А) Windows (терминал в Visual Studio, VS Code или PowerShell)
   1. Положите count_1H_descriptions.py в папку.
   2. В терминале перейдите в эту папку:
          cd "C:\путь\к\папке"
   3. Запустите скрипт с одним или несколькими файлами SI:
          python count_1H_descriptions.py "C:\путь\к\SI_1.pdf" "C:\путь\к\SI_2.pdf"
      (Если PDF лежит в той же папке, достаточно имени файла.
       PDF можно также перетащить из проводника в окно терминала.)
   Параметры:  -o ИМЯ   имя таблиц результата (по умолчанию 1H_descriptions)
               --help   список параметров

Б) Google Colab (на компьютер ничего устанавливать не нужно)
   1. Вставьте весь скрипт в ячейку кода и запустите её.
   2. Загрузите файл(ы) SI, когда появится запрос.
   3. Скачайте таблицы с результатами на панели «Файлы» слева.


5. Результат
------------
На экране для каждого файла SI:
    число описаний ¹H, описаний ¹³C и значений HRMS «found»;
    число повторяющихся меток и описаний, помеченных как, возможно, известные;
    candidate n = описания без пометок (проверить вручную);
    все метки в порядке SI («?» - метка перед описанием не найдена).

Две таблицы в папке, из которой запущен скрипт (одна строка на описание ¹H):
    1H_descriptions.xlsx   для Excel (правильно открывается в любой языковой версии)
    1H_descriptions.csv    стандартный CSV (через запятую, UTF-8) для Python, R и т. п.

Колонки:
    file          имя файла SI
    index         номер описания в порядке SI
    label         метка соединения перед описанием ("" - не найдена)
    flags         KNOWN? / CITATION / REPEAT; пусто, если пометок нет
    description   полный текст описания: от «1H NMR» до следующего блока данных
                  (ЯМР 13C/19F/31P/11B, HRMS, IR, т. пл., Rf, [α]);
                  не более 4000 символов

Обе таблицы перезаписываются при каждом запуске. Чтобы сохранить результаты
нескольких запусков, задайте другое имя через -o (например, -o counts_SI001),
переименуйте файлы или укажите все PDF в одной команде.


6. Частые проблемы
------------------
«Permission denied: 1H_descriptions...»
    Таблица открыта в Excel. Закройте её и запустите скрипт снова.

«The package ... is missing»
    Установите пакеты (см. 3. Что нужно) и запустите скрипт снова.

«python» или «pip» не является внутренней или внешней командой
    Python не установлен или не прописан в PATH. Установите Python с python.org
    и при установке отметьте «Add Python to PATH».

Предупреждение о «mkl-service» (от numpy)
    Безвредно и не связано с этим скриптом; скрипт его скрывает.
    Необязательное исправление: pip install mkl-service

Описание обрезано или содержит посторонний текст
    Извлечение текста из PDF не идеально (двухколоночная вёрстка, рисунки внутри
    текста, необычные шрифты). Всегда сверяйте с PDF.

«?» вместо метки
    Метка записана в форме, которую скрипт не распознаёт (например, только
    жирным шрифтом, без скобок). Само описание при этом в таблице есть.


7. Ограничения
--------------
- Описания, приведённые только в таблицах или в виде изображений, не находятся.
- Надстрочные ссылки распознаются, только если PDF хранит их как надстрочный
  текст; ссылки в другой форме могут быть пропущены.
- Скрипт не решает, является ли соединение новым; он только отмечает кандидатов.
