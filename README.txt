# nmr-1h-description-tools

Scripts for the survey of published ¹H NMR descriptions (Organic Letters, first half of 2026).
Author: Artur V. Eshtukov-Shcheglov. The code was written with the assistance of Claude Opus 5.5 (Anthropic) and was reviewed and tested by the author.

| Folder | What it does |
|---|---|
| [count_1H_descriptions](count_1H_descriptions/) | Finds all text ¹H NMR descriptions in SI PDF files, with compound labels and flags for probably known compounds |

The folder has its own README in English and Russian. The output of the script must be checked by hand.

License: MIT (see [LICENSE](LICENSE)).

Скрипты для исследования опубликованных описаний спектров ¹H ЯМР (Organic Letters, первое полугодие 2026 г.).
Автор: Артур В. Ештуков-Щеглов. Код написан с помощью Claude Opus 5.5 (Anthropic), проверен и протестирован автором.

| Папка | Что делает |
|---|---|
| [count_1H_descriptions](count_1H_descriptions/) | Находит все текстовые описания спектров ¹H ЯМР в PDF-файлах SI, с метками соединений и пометками для вероятно известных соединений |

В папке есть свой README на английском и русском. Результат скрипта нужно проверять вручную.
